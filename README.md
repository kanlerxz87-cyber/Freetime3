# Freetime3

Free Time Vacation Planner for SF Bay Area (Outer Sunset 94122) sports radio conflicts.

## Live Site
- GitHub Pages: serve from repository root (redirects to `site/index.html`).

## What it does
- Tracks conflict windows for: MLB (Giants/A's high priority; all 30 MLB clubs in scope), NFL (49ers high priority; all NFL games), Stanford NCAAF, Cal NCAAF, Westwood One Sports national NFL radio broadcasts.
- Defines "free" as minutes when none of those are on air.
- Provides executive summary, calendar/scoreboard, schedule tables, radio/broadcast sources, verification log, and flagged review page.

## Verification policy
- Every table row must have an official source link.
- If a value can't be confirmed from an official source, it is left blank and flagged as unverified.
- Never infer or fill in values.
- 2027-2029 schedules not officially released are marked ESTIMATED.

## Key finding
Under the strict conflict definition, there is almost no reliable 1-3 week zero-conflict vacation window in 2027-2029. The only plausible gaps are short post-Super Bowl / pre-MLB-spring-training windows (ESTIMATED; verify official dates). See `site/index.html`.
